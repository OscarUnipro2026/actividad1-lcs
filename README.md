# Actividad 1 - Diseño Avanzado de Algoritmos

Comparación de tres algoritmos para encontrar la subsecuencia común más larga (LCS) de dos cadenas.

## Archivos

- lcs_recursiva.py: recursividad directa.
- lcs_hirschberg.py: divide y conquista.
- lcs_dinamica.py: programación dinámica tabular.
- main.py: ejecución y comparación de los algoritmos.

## Requisitos

Tener Python 3 instalado. No es necesario instalar librerías adicionales.

## Ejecución

Descargar los archivos y abrir una consola en la carpeta del proyecto.

Ejecutar el siguiente comando:

    python main.py

El programa realiza pruebas con cadenas de 5, 10, 15, 100, 500 y 1000 caracteres y muestra el tiempo de CPU, el consumo de memoria y la longitud de la subsecuencia obtenida.

La versión recursiva tiene un límite de espera de 5 segundos y las otras dos versiones de 60 segundos.
